# OlahRasa Mobile
**Olah Bahan Sisa, Jadi Suatu Rasa**

## 1. Deskripsi Aplikasi
OlahRasa Mobile merupakan aplikasi berbasis Flutter
yang dikembangkan sebagai kelanjutan dari proyek
website OlahRasa pada Proyek Tengah Semester.

## 2. Anggota Kelompok

- Inventaris : VELICIA WILLY
